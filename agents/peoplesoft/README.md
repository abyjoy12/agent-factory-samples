# PeopleSoft demos

- [PeopleSoft Campus Capacity Review](campus-capacity-review/) — Review class enrollment and waitlist counters by institution, career and term without making enrollment promises.
- [PeopleSoft Database Service Pulse](database-service-pulse/) — Translate live PDB tablespace capacity, session counts and interval metrics into a business-service monitoring brief.
- [PeopleSoft Invoice Duplicate Review](invoice-duplicate-review/) — Surface repeated supplier invoice references for AP review with deterministic SQL and explainable matching.
- [PeopleSoft Learning Capacity Review](learning-capacity-review/) — Review learning offering enrollment and waitlist capacity without asserting eligibility or available seats.
- [PeopleSoft Learning Evidence Review](learning-evidence-review/) — Prepare a training-evidence review queue using completion dates, raw enrollment status, and target dates.
- [PeopleSoft Position Coverage Review](position-coverage-review/) — Review nonconfidential position capacity alongside current effective-dated assignment counts without making employee decisions.
- [PeopleSoft Purchase Order Review](purchase-order-review/) — Prepare a buyer review of purchase-order headers and line counts while preserving business-unit and raw status scope.
- [PeopleSoft Service Case Workload](service-case-workload/) — Review non-secure CRM case workload by business unit, raw status and priority without exposing case text.
- [PeopleSoft Workforce Planning Brief](workforce-planning/) — Explain department staffing and FTE using effective-dated assignments and nonconfidential catalogs.
