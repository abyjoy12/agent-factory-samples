# EBS Agent Blueprint Showcase

EBS Agent Blueprint Showcase is the new application intended to demonstrate the reusable business-agent blueprint, OPAF 26.10 workflows, MCP business tools, business evaluation and case/worklist integration.

Create it with a fresh App ID assigned at implementation. The existing Planning App remains unchanged and supplies the first sample business case. The Business Agent Workbench is the separate registry/testing and case-management companion.

This is a design identity, not a created APEX application. Its exact workspace, application ID, page design and native deployment must be resolved before generation/import. No application ID is reserved or reused by this documentation.

See the [application identity map](application-identity.json) and the [Planning App reference adapter](../planning-sample/README.md).
