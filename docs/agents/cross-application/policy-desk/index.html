What it demonstrates

Who needs to approve a $750 freight expedite—and which policy says so?

  • File upload, Text combiner, and document-grounded Agent
  • A cited answer from a small handbook and a clear response when the rule is absent.
  • Business-focused follow-up with traceable evidence and explicit limitations.

Connection context

Builder-uploaded fictional policy handbook; no application database is required.

Agent Memory

No learned user memory is required; evidence is obtained for each run.

Safety controls

  • Read-only data access; no sending, posting, approvals, payments, dispatch commits or database administration.
  • Historical application dates remain historical. The agent must disclose empty or failed results.
  • Currency, organization, join grain and evidence limitations remain visible. Integration users are for demos, not per-person application authorization.

Import and configure

  1. Import the release .paf with the repository archive passphrase. Imported flows are unpublished until reviewed.
  2. Upload the supplied paf-demo-policy-handbook.txt using the corresponding Builder component and select the uploaded filename.
  3. Select AIW26-PAF-HOL6004-BOO6096 on every Agent node. This OpenAI Compatible connection is configured on build.oracleagentfactory.com and is the required model for the final AI World lab instances. Configure that same model name in each destination; model definitions and credentials are not bundled.
  4. Disable Agent Memory and sharing between chat threads for this flow. This instance enables them by default; the official export does not include those switches. Run the documented primary prompt, inspect the evidence and dates, then publish for the demo audience.
  5. Read the numbered sticky notes from left to right. Agent Description provides workflow details and sample questions; use its expand control to read the full guide. The 2026-10-18 layout/model update preserves the workflow wiring and documented memory mode; the earlier validation record describes the original demo runs.
