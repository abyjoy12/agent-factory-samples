Safety controls

  • One GET operation; no application action or message-sending tool.
  • Bounded query and projection instructions. Factory does not enforce OpenAPI enums/defaults; verify actual calls and restrict credentials or use a gateway for hard limits.
  • A bounded opportunity sample is not a forecast. Keep currencies separate; probabilities, stage meanings and close-date commitments need owner confirmation. Do not score individuals or send messages.
  • Agent Memory and sharing between chat threads disabled; destination switches are configured separately.

Import and configure

  1. Follow integrations/fusion-apps/README.md; probe the destination resource and approved fields before creating a source.
  2. Import assets/openapi.json as a new REST source after replacing the example origin. Configure local authentication and organization scope where required.
  3. Import the encrypted sample as an unpublished draft and bind the REST API Tools node to the new source.
  4. Select AIW26-PAF-HOL6004-BOO6096 on the Agent. Disable both Agent Memory switches and save.
  5. Read the numbered notes and expanded Agent Description. Run the primary and limitations questions in Playground; inspect actual tool calls and response evidence before publishing.
