Safety controls

  • Removed generic database tools and the REST run controller from this copy.
  • Only six diagnostic routines are allowlisted; no run creation, cancellation or remediation tool is attached.
  • The database account privileges remain the security boundary; a package-wide EXECUTE grant can expose more routines to other clients.

Import and configure

  1. Import the release .paf into an unpublished destination flow.
  2. Provide the pre-existing PAF_DEMO.EBS_CHECK_API package and its control catalog. This sample does not install that custom backend. Use a control reader able to call the six documented routines; preserve the node routine allowlist and auto_commit=false.
  3. Select AIW26-PAF-HOL6004-BOO6096 on every Agent node. This OpenAI Compatible connection is configured on build.oracleagentfactory.com and is the required model for the final AI World lab instances. Configure that same model name in each destination; model definitions and credentials are not bundled.
  4. Create or select the sources listed in assets/source-bindings.json; replace every environment-local node binding.
  5. Check permissions and connectivity against the intended demo environment before publishing.
  6. Read the numbered sticky notes from left to right. Agent Description provides workflow details and sample questions; use its expand control to read the full guide. The 2026-10-18 layout/model update preserves the workflow wiring and documented memory mode; the earlier validation record describes the original demo runs.
