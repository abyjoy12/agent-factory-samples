Safety controls

  • Read-only data access; no sending, posting, approvals, payments, dispatch commits or database administration.
  • Historical application dates remain historical. The agent must disclose empty or failed results.
  • Currency, organization, join grain and evidence limitations remain visible. Integration users are for demos, not per-person application authorization.

  2. Create or reuse Oracle EBS Operations Read Only and rebind the nodes listed in assets/source-bindings.json.
  3. Select AIW26-PAF-HOL6004-BOO6096 on every Agent node. This OpenAI Compatible connection is configured on build.oracleagentfactory.com and is the required model for the final AI World lab instances. Configure that same model name in each destination; model definitions and credentials are not bundled.
