Safety controls

  • Read-only application access; no posting, approvals, payments, enrollment, messages, job restart or cancellation.
  • Historical dates, organization, currency, units and row grain stay visible; empty and failed queries must be disclosed.
  • The shared integration reader does not reproduce per-person application authorization.

Import and configure

  1. Import the generated .paf with the repository passphrase; keep it unpublished while reviewing.
  2. Rebind each database node to JDE Replica Procurement Read Only. Bind to the GoldenGate target JDEDEMO PDB, not the original JDEORCL source. Keep the source connections and published flows separate.
  3. Select AIW26-PAF-HOL6004-BOO6096 on every Agent node. This OpenAI Compatible connection is configured on the prepared PAF instance and is the required model for the final AI World lab instances. Configure that same model name in each destination; model definitions and credentials are not bundled.
  4. Disable Agent Memory and sharing between chat threads for this flow; those switches are not bundled in the official export.
  5. Run the primary prompt, inspect the actual evidence, and use the limitations follow-up.
  6. Read the numbered sticky notes from left to right. Agent Description provides workflow details and sample questions; use its expand control to read the full guide. The 2026-10-18 layout/model update preserves the workflow wiring and documented memory mode; the earlier validation record describes the original demo runs.
