What it demonstrates

Which backordered sales line is the best candidate for recovery?

  • Finds bounded sales-order backorder candidates and cross-checks line and header status.
  • Compares indicative inventory across branches and credible inbound purchase-order supply.
  • Produces an approval-ready recovery recommendation without changing JDE.

Connection context

The REST source statically supplies JPS920, role *ALL, and device paf-jde-agent. Basic Auth remains environment-local.

Agent Memory

Stateless grounded analysis; Agent Memory is not required.

Prerequisites

  • Private Agent Factory 26.7-compatible environment and an available LLM connection.
  • Network access from Agent Factory to a JD Edwards EnterpriseOne AIS server.
  • JDE Basic Auth user with read access to F4211, F4201, F41021, F4311, F4101, and F0101.

Safety controls

  • The OpenAPI definition exposes GET operations only.
  • Queries are bounded to 50 rows unless the user asks for more.
  • Recommendations distinguish evidence, assumptions, verification, approval, and execution.
  • Live analyses end with: JDE changes made: none (read-only analysis).

Import and configure

  1. Create a REST API data source from assets/jde-fulfillment-openapi.json; verify the AIS URL and configure JDE Basic Auth.
  2. Download and import the release PAF using the repository archive passphrase.
  3. Rebind the REST API Tools node to the new environment-local source.
  4. Select an available model, inspect tool calls, test the demo, and publish only after validating target-environment results.
  5. This catalog now uses the editor-owned consolidation copy. Configure the documented memory mode manually; official archives do not carry memory switches or learned memories.

Expected outcomes

  • Uses fully qualified JDE fields and does not invent business data.
  • Calls calculated balances indicative availability unless ATP is proven.
  • States what a human must verify or approve and performs no write-back.
